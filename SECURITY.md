# Security Policy

## Reporting a vulnerability

Please report security issues privately to Muhammad Rizwan Manzoor (https://github.com/rizwan6566-dev).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/rizwan6566-dev/voxgig-todoist-sdk/issues

## Scope

This policy applies to the generated Muhammad Rizwan Manzoor SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Voxgig Todoist Client public API, generated by
Muhammad Rizwan Manzoor. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
